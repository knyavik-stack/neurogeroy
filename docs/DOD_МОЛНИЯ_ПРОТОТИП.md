# DEFINITION OF DONE — прототип «Молния», Фаза 0

**Статус:** Прототип Фазы 0.  
**Не является** выполнением критерия Must по «Молнии» из PRD (Документ 4).  
Полная версия с 3+ уровнями сложности — отдельная задача Фазы 1.

---

## Готово, когда выполнено всё до единого пункта:

1. Партия длится 40–90 секунд (диапазон Документа 5).
2. Правила понятны без длинного текста (новый человек понимает, что делать, за 5–7 секунд или с одного примера).
3. Первая партия у нового игрока почти гарантированно успешная.
4. После партии сразу виден результат: точность и/или время реакции + полученный опыт/монеты.
5. Есть кнопка «Ещё раз».
6. Ошибка не ощущается как наказание — можно сразу попробовать снова.
7. Партия пишет в БД минимум: точность (%), среднее время реакции (мс), количество ошибок (таблица `game_sessions`).
8. Прогресс (уровень, опыт, монеты) сохраняется после закрытия и повторного открытия.
9. Работает на телефоне внутри Telegram (проверено хотя бы на одном реальном устройстве).
10. После прохождения партии у человека, который делает это первый раз, возникает желание нажать «Ещё раз».

**Ничего сверх этого списка не требуется и не поощряется.**

## Список запретов (та же задача)

- Не делать звук.
- Не делать сложные анимации.
- Не делать несколько режимов сложности.
- Не делать магазин, косметику, кастомизацию персонажа.
- Не оптимизировать «на будущее» и не закладывать архитектуру под фичи, которых нет в этом ТЗ.
- Не добавлять ничего, чего нет в DoD выше.
