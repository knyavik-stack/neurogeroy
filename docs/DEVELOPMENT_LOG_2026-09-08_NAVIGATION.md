# NeuroГерой — журнал исправления навигации и прогресса

Дата: 2026-09-08

## P0: навигация и доступность приложения

Пользовательский сценарий был признан сломанным до уровня блокирующего дефекта: из игр нельзя гарантированно вернуться в каталог, из прогресса нельзя гарантированно вернуться к играм, Telegram мог получать старую точку входа, а рабочей считалась фактически только старая «Молния».

### Что изменено

1. `root_entry.js` теперь является совместимым каноническим входом и делегирует запросы в `main_app.js`.
2. `wrangler.toml` теперь указывает `main = "root_entry.js"`. Это дополнительно защищает от старых конфигураций, которые уже использовали `root_entry.js`.
3. Для всех страниц `/games/*` и `/progress` добавлена гарантированная видимая кнопка `‹ К играм`.
4. В Telegram WebApp для страниц игр и прогресса подключается `BackButton`; его действие ведёт в корневое меню.
5. Навигация использует абсолютный URL относительно текущего origin, чтобы не зависеть от текущего пути WebView.
6. Корневое меню и API прогресса остаются в `main_app.js`; игровые механики в эту задачу не расширялись.

## Проверка

- `root_entry.js` проверен локально через `node --check`.
- Репозиторий остаётся единственным целевым GitHub-репозиторием проекта: `knyavik-stack/neurogeroy`.
- Production/Telegram smoke-test из этого окружения выполнить нельзя: доступ к реальному Telegram WebView и Cloudflare deployment не предоставлен. Поэтому факт публикации именно этого коммита в Telegram не объявляется подтверждённым.

## Следующий P0

Перед доработкой игровых механик требуется подтвердить в реальном Telegram:

- открывается корневое меню;
- открывается `/games/lightning`;
- из игры кнопка `К играм` возвращает в меню;
- открывается `/progress`;
- из прогресса кнопка `К играм` возвращает в меню;
- Telegram `BackButton` выполняет то же действие;
- прогресс загружается для авторизованного Telegram-пользователя.

После подтверждения навигации отдельной задачей проверяется каждая игра и только затем возвращается работа над игровым интерфейсом и механиками.
