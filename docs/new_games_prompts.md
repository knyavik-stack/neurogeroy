# НЕЙРОГЕРОЙ: СПЕЦИФИКАЦИЯ 5 ПРОРЫВНЫХ КОГНИТИВНЫХ ИГР
*Документ разработан для передачи в ИИ-разработчик (Cursor / Claude / Lovable) для быстрой реализации через Vibe-Coding.*

---

## ВВЕДЕНИЕ ДЛЯ ИИ-РАЗРАБОТЧИКА
Ты реализуешь мини-игры для когнитивного тренажёра «НейроГерой» (Telegram Mini App). 
**Общие ограничения разработки (по ТЗ проекта):**
1. **Стек:** HTML5 Canvas или легковесный React. Без тяжелых библиотек.
2. **Палитра:** Тёмный фон (`#0B1220`), акценты — бирюзовый (`#06B6D4`), оранжевый (`#F97316`), фиолетовый (`#8B5CF6`).
3. **Время сессии:** 40–90 секунд.
4. **Управление:** Максимально простое (тапы, простые свайпы), адаптированное под мобильные экраны Telegram.
5. **Динамическая сложность:** Если точность игрока >85%, сложность растет; если <60% — падает.

## ИГРА 1. «НЕЙРО-ЭХО» (NEURO-ECHO)
### 🧠 Когнитивный фокус: Темпоральное предсказание (Time-to-Contact) и моторно-сенсорная координация.
*Научная ценность:* Большинство игр тренируют реакцию на уже случившееся событие. Эта игра оценивает способность мозжечка и лобных долей предсказывать физическое событие во времени (развивает внутренний тайминг и планирование действий).

### 🎮 Игровой процесс для ребёнка:
На темном экране в случайных местах загораются неоновые «нейро-узлы» (бирюзовые круги). Из центра экрана во все стороны расходится круговая волна («импульс эха»). 
Задача ребенка — нажимать на нейро-узлы **ровно в тот момент**, когда круговая волна импульса пересекает их центр.
*   **Идеальное попадание (точно в момент пересечения):** Узел взрывается оранжевой вспышкой, звук «Дзинь», пишется «ИДЕАЛЬНО!».
*   **Слишком рано / поздно:** Узел тухнет, пишется «Мимо» или «Почти».

### 🛠️ Инструкция по реализации для ИИ:
1. **Рендеринг:** Используй HTML5 `<canvas>`.
2. **Логика волны:** Запусти циклическое расширение радиуса круга волны $R$ со скоростью $V$.
3. **Узлы:** Массив объектов `nodes: {x, y, targetRadius, status}`.
4. **Определение клика:** Когда пользователь тапает по экрану, находим ближайший узел. Проверяем расстояние $D$ от центра импульса до узла. Если текущий радиус волны $R$ близок к $D$ (с допуском во времени $\pm 100\text{мс}$ на легком уровне, $\pm 40\text{мс}$ на сложном) — это успех.
5. **Рост сложности:** 
   * Увеличивается скорость волны.
   * Волна идет не из центра, а из случайного узла.
   * Одновременно запускаются 2 волны разного цвета (нужно реагировать только на волну своего цвета).

## ИГРА 2. «КВАНТОВЫЙ МОСТ» (QUANTUM BRIDGE)
### 🧠 Когнитивный фокус: Когнитивное торможение (Inhibitory Control) и разделенное внимание.
*Научная ценность:* Игра заставляет мозг одновременно обрабатывать два параллельных процесса и подавлять автоматические импульсы (эффект Струпа нового поколения в игровой форме).

### 🎮 Игровой процесс для ребёнка:
Экран разделен вертикально на две половины: левая — бирюзовая («Мир Света»), правая — оранжевая («Мир Тени»). По обеим половинам снизу вверх летят неоновые частицы (фигуры).
Правило игры динамически меняется каждые 15 секунд:
*   **Правило 1 (Прямое):** Тапай по фигурам на той стороне, где они летят.
*   **Правило 2 (Инверсия):** Если фигура летит на *левой* стороне — нужно тапнуть по *правой* (симметрично), и наоборот.
*   Переключение правил сопровождается яркой вспышкой по центру и предупреждением «ИНВЕРСИЯ КАНАЛА!» / «ПРЯМОЙ РЕЖИМ!».

### 🛠️ Инструкция по реализации для ИИ:
1. **Структура данных:** Объект игры хранит `currentRule` (DIRECT или INVERTED).
2. **Генерация частиц:** Две независимые дорожки (левая $X \in [0, W/2]$, правая $X \in [W/2, W]$). Частицы летят вверх с постоянной скоростью.
3. **Обработка тапа:** 
   * При тапе по координате `touchX`:
   * Если `currentRule == DIRECT`: проверяем столкновение с частицей на той же стороне, где был тап.
   * Если `currentRule == INVERTED`: зеркально отражаем координату тапа `targetX = W - touchX` и проверяем столкновение на противоположной стороне.
4. **Рост сложности:** 
   * Скорость полета возрастает.
   * Правила меняются быстрее и хаотичнее.
   * На сторонах появляются ложные «статичные мины», которые взрываются при тапе.

## ИГРА 3. «СИНЕСТЕЗИЯ» (SYNESTHESIA)
### 🧠 Когнитивный фокус: Мультимодальная интеграция информации (кросс-сенсорный синтез).
*Научная ценность:* Впервые игра связывает звук и визуальный образ в динамическое когнитивное уравнение. Тренирует височную и теменную кору головного мозга, отвечающие за ассоциативное мышление.

### 🎮 Игровой процесс для ребёнка:
В начале раунда задается «Сенсорный Код» (например, «Высокий звук = Оранжевый треугольник», «Низкий звук = Бирюзовый круг»).
На экране появляется объект. Одновременно телефон издает короткий звук (высокий или низкий). 
Задача ребенка — мгновенно определить, **соответствует ли звук визуальному объекту** согласно правилу.
*   Если соответствует — свайп вправо (зеленый glow-эффект).
*   Если противоречит (например, звук высокий, а на экране бирюзовый круг) — свайп влево (оранжевый glow-эффект).

### 🛠️ Инструкция по реализации для ИИ:
1. **Аудио-синтезатор:** Используй Web Audio API (без внешних аудиофайлов!). Генерируй чистые тона: Высокий ($880\text{ Гц}$) и Низкий ($220\text{ Гц}$) через `OscillatorNode`.
2. **Генерация раунда:** 
   * Создаем правило: `currentMap = { highSound: 'triangle', lowSound: 'circle' }`.
   * Спавним случайную комбинацию: (звук, фигура).
3. **Распознавание жестов:** Реализуй детекцию свайпов (`TouchStart`, `TouchEnd`). Рассчитывай вектор смещения $\Delta X$.
4. **Рост сложности:**
   * Добавляется третий элемент (Средний тон / Квадрат).
   * Правило меняется прямо на лету: «Внимание! Правила поменялись местами!».
   * Сокращается время на принятие решения (от $2.5\text{ сек}$ до $0.8\text{ сек}$).

## ИГРА 4. «АРХИТЕКТОР МЫСЛЕЙ» (THOUGHT ARCHITECT)
### 🧠 Когнитивный фокус: Пространственная изоморфность и 3D-проекция.
*Научная ценность:* Тренирует пространственное воображение (Spatial Reasoning) и рабочую память. Вместо скучного вращения кубиков, ребенок учится мысленно «сворачивать» и анализировать сложные сетевые структуры.

### 🎮 Игровой процесс для ребёнка:
Слева на экране показана плоская 2D-схема из соединенных светящихся точек (граф-созвездие). Справа вращается красивая 3D-модель (из тех же точек и связей, но в объеме).
Ребенку нужно ответить: **это одна и та же структура или они отличаются?** (в 3D-модели может быть разорвана одна связь или перепутаны местами две точки).
*Ребенок может пальцем вращать 3D-модель, чтобы рассмотреть ее под нужным углом.*

### 🛠️ Инструкция по реализации для ИИ:
1. **3D Рендеринг:** Реализуй простую проекцию 3D точек $(X, Y, Z)$ на 2D плоскость экрана с помощью базовых матриц вращения (без тяжелого Three.js, чисто через Canvas 2D, чтобы Mini App весил $50\text{ Кб}$).
2. **Генерация графа:** 
   * Создаем массив вершин `nodes` (например, 5 точек) и матрицу смежности `edges` (связи).
   * Для 3D-модели применяем случайное вращение по осям X, Y, Z.
   * С вероятностью 50% вносим изменение: удаляем одну связь из `edges` или меняем координаты двух вершин.
3. **Интерактив:** Считывай `touchmove` для изменения углов вращения $\theta$ и $\phi$ 3D-модели.
4. **Рост сложности:**
   * Увеличивается число вершин графа (от 4 до 9).
   * Вершины окрашиваются в разные цвета (нужно сверять не только связи, но и цвета узлов).

## ИГРА 5. «ЭФФЕКТ ДОМИНО» (DOMINO CASCADE)
### 🧠 Когнитивный фокус: Проактивный когнитивный контроль, упреждающее планирование и оценка причинно-следственных связей.
*Научная ценность:* Развивает исполнительные функции (Executive Functions). Ребенок должен не реагировать на стимулы, а полностью рассчитать цепочку событий в уме *до* первого действия.

### 🎮 Игровой процесс для ребёнка:
На экране расположено созвездие «спящих нейронов» (круги с таймером внутри, например: $1.0\text{с}$, $0.5\text{с}$, $2.0\text{с}$). 
Когда импульс попадает в нейрон, тот "заряжается" указанное время, а затем взрывается сферической волной, которая может задеть соседние нейроны.
Задача ребенка — **поставить ровно один «стартовый заряд»** в такое место на экране, чтобы запущенная цепная реакция разбудила абсолютно все нейроны на поле за один раз.

### 🛠️ Инструкция по реализации для ИИ:
1. **Моделирование цепной реакции:** 
   * Каждый нейрон имеет состояние: `IDLE`, `CHARGING`, `EXPLODING`, `ACTIVATED`.
   * При взрыве нейрона $A$, запускается радиальная волна радиуса $R$. Если центр нейрона $B$ попадает в радиус взрыва, нейрон $B$ переходит в режим `CHARGING`.
2. **Интерфейс планирования:**
   * Ребенок водит пальцем по экрану — вокруг пальца показывается зона поражения стартового взрыва.
   * Нажатие на кнопку «СТАРТ» фиксирует точку взрыва и запускает симуляцию.
3. **Рост сложности:**
   * Нейроны начинают медленно двигаться по экрану.
   * Появляются «блокирующие узлы» (черные дыры), которые поглощают взрывную волну.
   * Нужно запустить реакцию так, чтобы нейроны взорвались строго в определенном порядке (например, от меньшего таймера к большему).
