## DEFINITION OF DONE

Обязательны **все** пункты из файла `DOD_МОЛНИЯ_ПРОТОТИП.md`.  
Повторяю ключевые:

- Партия 40–90 секунд
- Правила понятны быстро
- Первая партия почти гарантированно успешная
- После партии виден результат (точность / время реакции + опыт/монеты)
- Кнопка «Ещё раз»
- Ошибка не наказывает
- Запись в БД: точность, время реакции, ошибки
- Прогресс сохраняется
- Работает на телефоне внутри Telegram
- Хочется нажать «Ещё раз»
