# NeuroGeroy — контекст для Кодера

Telegram Mini App + бот.  
Когнитивный тренажёр-игра для детей 9–13 лет.  
Полный устав лежит в папке `/docs`. Читать по необходимости, не всё сразу.

## Сейчас делаем

**Фаза 0:** рабочий каркас (бот + Mini App) + один прототип мини-игры «Молния».

DoD и запреты — в файле `/docs/DOD_МОЛНИЯ_ПРОТОТИП.md`.  
Не отклоняться от списка.

## Стек (не менять без явного решения CEO)

- Frontend: React или чистый HTML/JS + Telegram Web App API
- Backend: Node.js или Python (простой REST / serverless)
- База данных: Supabase (PostgreSQL)
- Бот: Grammy (Node) или aiogram (Python)
- Хостинг: Vercel или Cloudflare Pages

## Таблицы БД на этом этапе

- `users` — telegram_id, имя персонажа, уровень, опыт, монеты
- `game_sessions` — id игрока, игра, точность, время реакции, ошибки, дата
